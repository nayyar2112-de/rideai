🎙️ Presenter Script
💡 Presentation Tips
🎙️
Lead with the voice demo
Open by saying "Watch what happens when I just speak" — then trigger a voice command. Let the audience see the AI respond before explaining anything.
📱
Use Expo Snack live
Open snack.expo.dev on a second screen or tablet. Paste SnackApp.js and show it running in real time. Audience can scan the QR code on their phones.
🤖
Emphasise AI transparency
The matching screen showing "Why Rahul?" is a key differentiator. Pause on it. Explain that this is what agentic AI looks like — not a black box.
📊
Hit the 23% stat hard
The booking abandonment rate is your killer stat. Open with it, close with it. It makes the problem real and the solution measurable.
♿
Mention accessibility
Voice-first design is an accessibility superpower. Mention visually-impaired users, elderly users, users with motor impairments. It broadens the market story.
🚀
End with the GitHub link
The code is live on GitHub right now. Saying "you can clone and run this today" gives your demo instant credibility. It's not a mockup — it's real.
